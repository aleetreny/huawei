The task

A DeepSeek agent lives a 48-month career

month: 3 stories, effects hidden quarter: Energy and a main action review every six months: a chance to be promoted

Ways to lose

Never promoted, and dismissed · hidden risk blows up twice, a trust crisis · burnout or ruin

The only gauge of hidden risk

The tone of the monthly HR remark, as the Skill classifies it:

friendly quiet uneasy frowning angry

Q1 · How we thought

Three questions behind every decision

1

What does this option probably change?

A reading guide in general words: what tends to move each stat and hidden risk. No event names, no answers.

2

What does the career need now?

Fixed priorities: stay in the run, then win the next review, then grow.

3

Which rule applies in this phase?

Scope: a switch the agent computes, Review in N.

Why question 1 is the hardest

Q1 · How we thought

The decision loop the Skill sets

Every note starts with the status line: the agent's memory and the scope switch

Review in N | Now S.. N.. O.. | Best S.. N.. O.. | Reviews here: 0

Review rules switch on only when N is 1 or 2 · Best resets on promotion · notes survive summaries

Turn loop: answer each situation with ONE reply whose tool_calls array holds exactly two calls … drop options that may bury a problem … In the two months before a review, keep Network and Output at their best … From level 4 on, every quarterly phase goes to Skill … Every note is one line.”

With several Skills, the agent opened the one that looked relevant and missed rules in another. It reads the Skill early and then works from context, so the manifest carries what matters most.

Q2 · From the logs to the changes

What the logs showed, and the rule it became

Promotions lost by one point of Network or Output, in the last story before a review

→
In the two months before a review, keep Network and Output at their best this level and repair any loss at oncemanifest · plus the Best value in the status line

Options that sounded responsible, like a private talk or a phased fix, carried hidden risk the model missed

→
drop options that may bury a problem (private, anonymous, partial, later, hidden, skipping work to save time)manifest · plus a strict mode when the HR remark is not friendly

The agent obeyed the review rule but misread costs: its notes treated a polite refusal as keeping Network

→
Network falls whenever someone is let down, even politely or fairlySKILL.md · Story step 4, “Read the hidden costs”

Q2 · From the logs to the changes

Every call resends the whole history

Before · several replies per decision

reply → take_action(…) reply → observe(…)

each reply resends everything so far, so cost grows faster than the number of replies

Now · one reply, two tool calls

tool_calls: [take_action(…), observe(…)]

DeepSeek kept this pattern only when the Skill showed the literal shape of the reply

Q2 · From the logs to the changes

A fix that made play worse

mv-4 = mv-3 + one manifest line, added after a career was stopped by the runner when 21 replies carried no tool call: “Never end a reply with text only … put the decision in the take_action call, not in prose.”

Hypothesis, not proven: the line removes the short written reasoning the model needs when its provider does not reason privately. Development careers with the official runner and DeepSeek, not official scores.

Q3 · Scripts and reference files

None, by choice

Advisor script · a teammate's line

One excellent career, too many early ends

Its best career reached the sixth level, but 3 of its 7 careers ended early, and complete ones used about 1.6 times the tokens.

Script with state · our research replica

Added nothing

What fails is reading the options, and a script reads them no better than the model that feeds it.

Reference files

Not reopened

The agent read the Skill early and did not reopen supporting files.

Scripts that use only data from the current run were allowed by the organisers. mv-3 is one Skill and the manifest: no scripts, no reference files.

Q4 · Generality and robustness

Built only on what the agent can see

The Skill relies on

  • the tone of the HR remark
  • review talks and warnings
  • effects shown in the quarterly menu
  • its own one-line notes
  • the published calendar: a review every six months, with protection kept on if the talk comes late

No event titles, fixed answers or hidden thresholds. Our observations are marked as ours, and the game's signals come first. Turn loop verified with two model providers.

Known limits

  • Perception: about one career in four still collapses, mostly at the starting level
  • Third review at the starting level: won by 1 of the 11 careers that reached it, lost to hidden risk rather than missing stats
  • The countdown assumes the six-month cycle
  • Some providers sometimes write a tool call as text

Q5 · Agents and Skills

Skills change how an agent works, not what it sees

Strong at

  • Format: one reply per decision cut tokens per month to less than half on average
  • Concrete quarterly directions are followed far more often than general goals

Weak at

  • Perception: “protect Output” is obeyed, yet the model misses which option costs Output
  • Scope: an earlier manual changed about 1 in 5 unrelated story choices
  • One sentence can change how the model plays, as mv-4 showed

Skills give an agent priorities and discipline, not understanding.
