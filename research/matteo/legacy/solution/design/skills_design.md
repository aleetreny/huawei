# Skill design: Sustainable Career v0.1

## Task and design intent

Guide one agent through a 48-month career, seeking a strong outcome across career level, wealth, wellbeing, capability, risk control and relationships. The public rules establish these directions but leave important formulas and conditions unknown. Instructions therefore prioritize contextual decisions and revision from current-run feedback.

The three Skills divide the work by decision responsibility. `career-risk-review` assesses the situation before an action and after important feedback. `career-event-decisions` compares story options using that assessment. `career-quarterly-planning` uses it to allocate Energy and select the main action. The same agent performs all steps. No team execution, delegate agent or script is required.

## Information flow

The agent reads the public handbook, observes the current session and identifies the active phase. It reads risk-review guidance first and applies the relevant decision Skill. A compact working assessment records the current concern, supporting evidence, useful correction and growth objective. This is current-run context, not a catalogue of event answers.

The agent submits one currently offered choice and a brief reason through the official action tool. It then observes consequences. Recent logs are consulted when feedback is ambiguous or a delayed issue needs context. The next decision uses the updated assessment. Repeatedly rereading the whole history without a reason is discouraged to limit token overhead.

## Why these responsibilities

Public failure directions already identify health, dignity, performance, capability, relationships, finances and accumulated risks as relevant. A separate random exploration found frequent early health and trust failures. This motivates testing explicit risk assessment; it does not validate a particular action policy or establish hidden rules. The submitted Skills contain no numerical weights inferred from that exploration.

Three Skills offer clear triggers with limited duplication. More files are not presumed to improve either play or the document-quality score. If testing finds routing failures or excessive overhead, consolidate the guidance before expanding it.

## Scripts and references

No executable helper or copied event catalogue is included. The task requires interpretation of live options rather than deterministic event matching. The public handbook is obtained through the official interface. This keeps the candidate independent of dataset files and avoids embedding unpublished thresholds or formulas.

## Validation status

Front-matter and structural checks verify packaging properties only. A manual Codex-assisted exercise tests readability and decision flow, not the designated model's behavior. The proposed official-model evaluation has not run because the competition key is not yet available. No claim of superior score or survival is made for this candidate.
