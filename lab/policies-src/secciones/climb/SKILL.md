# Climb again after every promotion

## After a promotion
- A promotion raises every cap, and the next bar is higher. Stories alone usually lift Network and Output too slowly to reach the new bar in one half-year, so the quarter-end actions must build them from the first allocation after the promotion: Prepare report materials and Network maintenance with the Energy, and Apply for a key project or Report results to your manager as the main action.
- Keep track of which input rose least since the promotion; that is the one to build.

## When Network and Output stop rising
- If Network and Output have stopped rising and the review still did not promote, the missing input is Skill. Skill takes the longest to build, so start early and keep going every quarter: Skill learning when Health allows, and Apply for rotation or Build a mentorship as the main action.
- In stories, prefer answers that build capability: learning, doing the work properly, taking on the harder part yourself.

## Grades and pay
After a promotion, strong review grades bring a bonus on top of the higher salary. Keep the inputs at their caps through each review and avoid answers that cost money.

## Never trade the base away
Building never overrides the basics: Defuse legacy risk after any risk remark, recover Health before it gets low, and keep Dignity healthy (a promotion also needs Dignity that is not low).
