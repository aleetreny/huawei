# Prospective BHR adherence rubric — not executed

This is an evaluation proposal, not a frozen registered trial or a gameplay tool.

For a later archived-prefix actor assessment, choose cases before seeing BHR answers and keep future trajectory/gold labels hidden. Prefer new cases for confirmation. Supply only the public prefix and the tested manual; evaluate comparable M1 responses separately. An annotator can use only the information then available. Mark ambiguous targets or undocumented option costs unscorable, never silently correct or incorrect.

Score these dimensions separately:

1. **Mode declaration:** one explicit mode and a public basis. BUILD is allowed when readiness is unknown. Do not require HOLD merely because statistics look high.
2. **HOLD entry:** reliable target support or all stated provisional-plateau conditions; no single-zero or personal-best shortcut. Record how often HOLD is identifiable and entered, not just conditional compliance.
3. **REPAIR entry:** an observed loss to the previously protected target is recorded as a deficit. Safety exceptions must be explicit.
4. **HOLD exit:** failed review causes renewed diagnosis; promotion resets level-specific targets; restoration is observed rather than assumed.
5. **Choice consistency:** the reason describes the actual selected option and serves the stated mode, subject to documented safety needs. Unknown effects remain unknown; an unchosen action has no observed counterfactual payoff.
6. **Memory integrity:** public source/time, actual versus advertised gains, attempts versus completion, incident history versus current calm, no fabricated identifiers.
7. **Channel compliance:** actual final note fits the public character limit and retains critical complete facts; declaration of compliance is not enough.

Report denominators, missing/ambiguous evidence, mode coverage, safety overrides and each failure category. A correct label with a contradictory choice fails consistency; a later stochastic loss does not by itself prove the original decision violated the manual. Use later observations only to assess the next update, not as information available to the earlier choice.

No numerical success criterion or sample size has been selected here. Specify those prospectively before model calls. Distinguish recall/mode adherence from promotion, survival and measured token use; a full-career comparison is required for the latter claims. An executable action gate would require a separate implementation and must not be represented as already present.
