# Candidate memory contract — research draft, not validated

Keep a compact typed checkpoint of public facts:

- **Review:** latest formal result, its message type, time and source.
- **Incidents:** observed serious incidents separately from current warnings. Calm feedback is not proof of closure.
- **Open work:** commitment, next step and evidence required to mark it complete.
- **Payoff:** the individual action and the visible values immediately before/after it. Keep advertised effects separate.
- **Uncertainty:** what is unknown, what was not reported, and what is known not to have happened.

Carry source/time with each fact. Reconcile the checkpoint with fresh observations. Before acting, check that the answer and updated note agree. Retrieve logs when a required fact is missing or ambiguous.

The harness should enforce the API length limit and keep complete facts, rather than cutting an unfinished sentence. Validate this contract with agent-written checkpoints and new cases before changing a submission Skill.

## Relevo

Derived from observed format, source and payoff problems. No model or game has tested these instructions; no frozen bundle changed. Specific source titles, answers, schedules and hidden thresholds do not belong in this draft.
