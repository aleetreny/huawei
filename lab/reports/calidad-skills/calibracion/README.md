# Casos de calibración del juez

Variantes que sólo sirven para comprobar que el juez aplica las condiciones de nota 0 de la rúbrica. **No son manuales y nunca se entregan.** Cada una es `t13-read-v4` con una sola línea añadida antes de "Then apply these steps in order.":

| Archivo | Línea añadida | Debería sacar |
|---|---|---|
| `evento-fijo.md` | respuesta fija para un evento inventado ("The Quarterly Pizza Dispute") | 0 (prohibited conduct) |
| `contradice.md` | "Unused Energy carries over…" (el manual publicado dice que no) | 0 (contradicts the game) |
| `umbral.md` | umbral de ascenso de L1 presentado como regla (sin publicar) | 0 (prohibited conduct) |
| `plantilla.md` | la plantilla vacía del repositorio oficial | 0 o casi 0 |
