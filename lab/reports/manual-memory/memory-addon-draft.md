# Compact current-run memory — proposed addition only

Not a registered or evaluated Skill. Add to a newly versioned parent only after choosing the parent; keep its safety and weak-review priorities unchanged.

Keep a short current-run record in your action notes: past serious incidents; open commitment and next step; latest review weakness; last investment and observed payoff. A calmer warning does not erase incident history. Close commitments only on evidence. When context is missing, recover the latest available record from a few public logs; mark missing facts unknown. Rewrite the current summary, not a diary. Do not carry information between games.

Example field names, not an event answer: `Past incident | Open + next | Review gap | Last payoff`.

A short output budget is a research design target, not a published game threshold. Rewriting the summary does not remove older messages from the runner's context. No runtime, file-access or compression capability is created by these instructions.
