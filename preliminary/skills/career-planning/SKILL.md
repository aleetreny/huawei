# Career Planning

## Purpose
Make choices that produce sustainable career progress over the full 48-month simulation. Apply this Skill within a single JiuwenSwarm `agent`, not a multi-agent team. Use only the official MCP interface.

## Operating procedure
1. Observe the current game state, including the current event, available actions, visible statistics, and simulation phase. If necessary, use the public handbook for action meanings.
2. Establish the current main need: immediate stability, capability growth, reliable output, stronger workplace relationships, or advancement. Consider the observed trend and past feedback, not a single statistic in isolation.
3. For each currently available event choice, qualitatively assess its potential effects on long-term progression, current resources, future optionality, and possible negative consequences. Do not claim access to unpublished numerical effects.
4. Consider the risk-management Skill before committing to a choice. An apparently high-reward option is less attractive when it threatens continued survival.
5. Select an option actually listed by `observe`; execute it through `take_action` with a concise justification. Observe the next state before deciding again.

## Quarterly Energy decisions
- Up to three Energy points are available per quarter and unused points do not carry forward. Use the public costs and effects when evaluating combinations.
- If Health or Dignity is falling or repeated warnings suggest vulnerability, favour recovery or relationship-preserving actions over additional high-intensity work.
- When sustainable, choose Skill learning (cost 2) if career capability is a limiting concern; network maintenance (cost 1) when workplace relationships need attention; and report preparation (cost 1) when output or review readiness needs improvement.
- High-intensity work improves Output but reduces Health and Dignity. Treat it as a deliberate short-term trade-off rather than a default action.
- Defuse legacy risk when within-run feedback indicates a meaningful unresolved legacy risk. Do not assume any hidden counter or exact probability.
- Re-evaluate remaining Energy after each step using the options the game actually presents.

## Quarterly main actions
- Compare the main actions using their publicly described directional effects. Key projects, result reporting, rotations, mentoring, showcasing results, relationship repair, and reducing risk support different needs.
- Prefer options whose effects complement the current career bottleneck without deepening severe risks.
- Review the need for stronger Output, Skill, and Network near public six-month review windows, without claiming a secret promotion threshold.
- Change priorities when review feedback or accumulated trends indicate that the current approach is not working.

## Generalisation and constraints
Never memorise named development events, manufacture an unavailable action, hard-code purported secret thresholds, or inspect the underlying simulation internals. Adapt the strategy from observed state and official feedback. Keep notes concise and avoid unproductive repeated deliberation.
