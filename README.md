# TechArena Career Survival Agent

## Start here

For contributors and coding agents joining the project:

1. Read the [exploratory findings and limitations](docs/exploratory-findings.md). This is the handoff from the four-hour, 73,858-session random baseline.
2. Read the [strategy experiment plan](docs/experiment-plan.md) before designing or evaluating Skills.
3. Use [Career Lab](tools/local-game/README.md) to explore the official simulator manually in a local browser, without a model API key.
4. Review [Sustainable Career v0.2](solution/README.md), the current three-Skill candidate, and its [evaluation plan](docs/skill-evaluation-plan.md). Official-model runs are pending the competition key and confirmed manifest identity.

The baseline identifies common failure patterns under random choices. It does not establish winning decisions, official hidden rules, or the performance of an AI agent. The next useful step is a controlled comparison of reasoned strategies using the competition-required platform and model.

All competition deliverables must be in English. Follow the [official competition rules](https://techarena-career-sim.readthedocs.io/en/latest/competition-rules.html) and [submission requirements](https://techarena-career-sim.readthedocs.io/en/latest/submission.html).

Latest manual experiment: [v0.2 growth pilot](docs/manual-skill-pilot-v02.md), 48 months completed, 73.4/100 at L5. Promotion dates matched the first pilot; results are exploratory.
