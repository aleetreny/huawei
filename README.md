# Huawei TechArena — Gradient Depression

Espacio de investigación del equipo para el reto *Career Survival Agent*. Repositorio privado.

**Empieza aquí:**
1. [ESTADO.md](ESTADO.md): dónde vamos, las líneas activas y las fechas.
2. [HALLAZGOS.md](HALLAZGOS.md): todo lo aprendido, ordenado por importancia.
3. [NORMAS.md](NORMAS.md): cómo trabajamos y cómo mantener esto ordenado.

| Carpeta | Qué hay |
|---|---|
| `careerlab/` | El laboratorio (Python): partidas por la vía oficial, registro, actores de Claude, lint de cumplimiento. Uso en [lab/README.md](lab/README.md) |
| `scripts/<línea>/` | Código de cada línea de trabajo (`ingenieria-inversa`, `question-bank`, `transmision`, …) |
| `lab/reports/` | Informes por línea, con índice en [lab/reports/README.md](lab/reports/README.md) |
| `lab/policies-src/` | Manuales (Skills) candidatos, cada uno con su `policy.json` |
| `lab/data/` | Datos de bots ya extraídos (llevan texto del juego: sólo para estudiar) |
| `lab/registry*/` | Exportes del registro de partidas |
| `docs/entrega/` | Guion del vídeo y presupuesto de DeepSeek |
| `docs/historico/` | Documentos de antes del 27 oct |

Nada de este repositorio es la entrega: la entrega final es un ZIP `solution/` en inglés (ver las reglas oficiales del runner).
