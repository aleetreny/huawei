The research directory is development material, **not a competition submission**. Do not include it wholesale in a final ZIP. The Spanish research summary is for the team; all actual preliminary and final deliverables must be English.

The hierarchical-laboratory package specifies the proposed Opus/Haiku/Sonnet development workflow. It has not launched a model fleet or validated a winning policy. It distinguishes search over policy variants from search over cloned game states, and keeps external development orchestration separate from the required single-agent evaluated runtime.

The official development runner is a separate public repository: [RAI-Internal/techarena-career-sim](https://github.com/RAI-Internal/techarena-career-sim). `scripts/setup_official_runner.sh` installs it; no model key is configured yet. Follow its pinned setup and [the official quickstart](https://techarena-career-sim.readthedocs.io/en/latest/quickstart.html). The current manual preview of Matteo’s interface is separate and runs at [Career Lab](http://127.0.0.1:8765); it is not a JiuwenSwarm benchmark.

No competition API credits, organiser messages or competition submissions were used during the initial research. The follow-up now includes ordinary manual gameplay; see the current exploration report for actual observations.
